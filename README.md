# TTMC

TTMC (Taiwan Typhoon Monitoring Center) is a professional typhoon monitoring and warning dashboard built with Next.js, TypeScript, and TailwindCSS.

## Features

- Dashboard with status summary and warning countdown
- Taiwan county signal map
- Typhoon track center
- Weather alert pages
- TTMC classification and signal rules
- Light and dark mode support

## Development

```bash
npm install
npm run dev
```

## Stack

- Next.js
- TypeScript
- TailwindCSS
- ECharts
- Leaflet / MapLibre-ready structure
